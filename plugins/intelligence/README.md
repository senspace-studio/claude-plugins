# Intelligence

Search across your company's records, see how its social accounts are received, and update the records with what people tell you and what the records show, writing only what the person approves.

You can also read the feedback people have given on these tools, with what the people who run them answered, and add your own. It reaches them where the server is set up to take it, and it never becomes one of the records.

The plugin is the intelligence MCP server together with skills that use it. Other connectors it needs are listed in [CONNECTORS.md](CONNECTORS.md).

## Connect

The server asks for a passphrase, set by whoever runs it.

- Claude Code: run `/mcp`, open the intelligence server, authenticate, and enter the passphrase on the page that opens.
- Claude on the web and Desktop: open the intelligence connector, connect, and enter the passphrase on the page that opens.
